# FlyRank FE-04 — Capstone Skeleton

This is a Next.js capstone skeleton with:

- App Router
- Tailwind CSS
- Routed placeholder screens
- Health-check API
- Health-check page that fetches live data
- No secrets committed to the repository

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

Health check:
http://localhost:3000/health

API:
http://localhost:3000/api/health

## Deployment

Connect this repository to Vercel or another Next.js-compatible deployment platform.
If needed, set `NEXT_PUBLIC_APP_URL` to the deployed application URL.
